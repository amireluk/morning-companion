# מה לובשים היום? 👕☂️

מסך לטאבלט שמראה לילדים מה ללבוש לפי תחזית מזג האוויר – כמעט בלי טקסט.
דמות מצוירת לובשת את הבגדים המומלצים; אם היום משתנה (בוקר קר, צהריים חמים) מופיעות כמה דמויות
עם חץ ותיק שמראה מה להוריד/להוציא. בשעות הערב המסך עובר לתחזית של **מחר**.

## איך זה עובד
- **תחזית**: [Open-Meteo](https://open-meteo.com) – חינם, בלי מפתח. טמפרטורה מורגשת, גשם, UV, לפי שעה.
- **מיקום**: זיהוי אוטומטי; אם אין – תל אביב. אפשר לבחור עיר בהגדרות.
- **שעות**: בודקים רק את החלון שבין היציאה (08:00) לחזרה (17:00), מחולק לבוקר/צהריים/אחה״צ.
- **כללים** (`js/outfit.js`, טבלה `T` בראש הקובץ – קל לכוונן):
  - שיא ≥22° → חולצה קצרה, אחרת ארוכה. שיא ≥23° וגם מינימום ≥17° → מכנס קצר.
  - מתחת ל־17° (או 20° עם חולצה קצרה) → סווטשירט. מתחת ל־12° → מעיל. מתחת ל־7° → כובע צמר, כפפות, צעיף.
  - גשם → מטריה; גשם כבד → מגפיים. חם מאוד בלי גשם → סנדלים. UV גבוה → כובע וקרם הגנה. מעל 29° → בקבוק מים.
  - בגדי הבסיס נקבעים לפי שיא היום, השכבות לפי כל חלק ביום – מכאן ה"להוריד לתיק".
  - פריט שצריך רק בהמשך היום (למשל מטריה לאחה״צ) מסומן בכרטיס עם תיק – לקחת מהבית.
- **לכל ילד**: גיל (7+ רואים גם מספרים ומילים), מראה, ו"חם לו / קר לו" שמזיז את הספים.
- **מסך**: נשאר דלוק ביום, מתעמעם בלילה (נגיעה מעירה לדקה). עובד גם בלי אינטרנט עם התחזית האחרונה.

## הגדרות
לחיצה ארוכה (שנייה) על גלגל השיניים בפינה. בפעם הראשונה ההגדרות נפתחות לבד.

## הצגה בלי אינטרנט (דמו)
`?demo=` עם אחד מ: `hot` `warm` `mild` `layers` `cool` `rain` `pmrain` `cold`.
אפשר להוסיף `&hour=19` כדי לראות את תצוגת "מחר".

## התקנה על טאבלט אנדרואיד
1. לפרסם ב־GitHub Pages: ‏Settings → Pages → Deploy from a branch → לבחור את הענף ואת `/ (root)`.
2. לפתוח את הכתובת ב־Chrome בטאבלט → תפריט ⋮ → **הוספה למסך הבית / התקנת אפליקציה**.
3. לאשר הרשאת מיקום.
4. מומלץ: להשאיר בטעינה, ובאפשרויות מפתחים להפעיל "Stay awake" (המסך לא נכבה בזמן טעינה).
