# מה לובשים היום? 👕☂️

מסך לטאבלט שמראה לילדים מה ללבוש לפי תחזית מזג האוויר – כמעט בלי טקסט.
למעלה שלושה אריחים – בוקר, צהריים, ערב – עם מזג האוויר והטמפרטורה.
לכל ילד דמות מצוירת שלובשת את מה ללבוש ביציאה מהבית, ולידה תיק עם מה לקחת להמשך היום
(מטריה לגשם של אחה״צ, סווטשירט אם יתקרר). בשעות הערב המסך עובר לתחזית של **מחר**.

## איך זה עובד
- **תחזית**: [Open-Meteo](https://open-meteo.com) – חינם, בלי מפתח. טמפרטורה מורגשת, גשם, UV, לפי שעה.
- **מיקום**: זיהוי אוטומטי; אם אין – תל אביב. אפשר לבחור עיר בהגדרות.
- **שעות**: בודקים רק את החלון שבין היציאה (08:00) לחזרה (17:00), מחולק לבוקר/צהריים/אחה״צ.
- **כללים** – טבלה בהגדרות ("טמפרטורות ובגדים"): שישה טווחים לפי טמפרטורה מורגשת
  (קפוא מתחת ל־10°, קר מאוד עד 14°, קר עד 19°, קריר עד 23°, נעים עד 26°, חם עד 29°, חם מאוד מעל) עם גבולות שאפשר לשנות, ולכל טווח מה לובשים:
  חולצה, מכנס, נעליים, סווטשירט, מעיל, בגדי חורף, כובע שמש. וגם: מאיזה סיכוי גשם לוקחים מטריה
  וכמה מ״מ גשם ביום מחייבים מגפיים. ברירות המחדל ב־`js/outfit.js` (`defaultRules`).
  - חולצה, מכנס ונעליים לפי השעה החמה ביום; שכבות ובגדי חורף לפי כל חלק ביום.
  - מכנס קצר וסנדלים רק אם גם השעה הקרה לא דורשת סווטשירט.
  - מה שצריך רק בהמשך היום (צהריים/ערב) ולא לובשים בבוקר – נכנס לתיק.
- **לכל ילד**: גיל (7+ רואים גם מספרים ומילים), מראה, ו"חם לו / קר לו" שמזיז את הספים.
- **מסך**: נשאר דלוק; כשחשוך בחוץ (לפי התחזית) הוא מתעמעם קצת, ונגיעה מחזירה בהירות מלאה לדקה. עובד גם בלי אינטרנט עם התחזית האחרונה.

## הגדרות
בפעם הראשונה האפליקציה פשוט נפתחת – עם ילד אקראי (גיל, מראה) שנשמר במכשיר. עד 3 ילדים.
כל השאר בכפתור ☰ בפינה (טאב לילדים וטאב למזג אוויר ושעות). כל הילדים מוצגים יחד, באותה תלבושת.

## דמו
`demo.html` – עמוד אחד עם נתוני דוגמה ובורר מזג אוויר (טמפרטורה וגשם לבוקר ולאחה״צ).
נבנה מחדש עם `python3 tools/build_demo.py`. ההגדרות שלו נשמרות בנפרד מהאפליקציה האמיתית.

## הצגה בלי אינטרנט (דמו מתוך האפליקציה)
`?demo=` עם אחד מ: `hot` `warm` `mild` `layers` `cool` `rain` `pmrain` `cold`.
אפשר להוסיף `&hour=19` כדי לראות את תצוגת "מחר".

## התקנה על טאבלט אנדרואיד
1. האתר נבנה מ־`main` דרך GitHub Pages ‏(Settings → Pages → Deploy from a branch → `main`, `/ (root)`):
   https://amireluk.github.io/morning-companion/ (הדמו: `demo.html`). עבודה נעשית בענפים ונכנסת ל־`main` כשהיא מוכנה.
2. לפתוח את הכתובת ב־Chrome בטאבלט → תפריט ⋮ → **הוספה למסך הבית / התקנת אפליקציה**.
3. לאשר הרשאת מיקום.
4. מומלץ: להשאיר בטעינה, ובאפשרויות מפתחים להפעיל "Stay awake" (המסך לא נכבה בזמן טעינה).
